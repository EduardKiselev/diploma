
# USB Camera Capture

Скрипт для захвата фотографий со всех подключённых USB-камер с привязкой к физическим USB-портам.

## Возможности

- Автоматическое обнаружение USB-камер
- Привязка камер к физическим USB-портам (не зависит от порядка подключения)
- Конфигурация с дружественными именами камер
- Прогрев камер перед съёмкой (автоэкспозиция)
- Сохранение фото с timestamp и именем камеры

## Требования

- Linux (используется `/dev/v4l/by-path/`)
- Python 3.7+
- v4l-utils

## Установка

```bash
# Установить системные зависимости
sudo apt install v4l-utils

# Создать виртуальное окружение (опционально)
python3 -m venv venv
source venv/bin/activate

# Установить Python зависимости
pip install -r requirements.txt
```

## Использование

### 1. Инициализация конфигурации

При первом запуске или при добавлении новых камер:

```bash
python capture.py --init
```

Скрипт:

- Просканирует все подключённые USB-камеры
- Создаст файл `cameras.json` с найденными камерами
- Покажет список камер и их USB-порты

### 2. Настройка имён камер (опционально)

Отредактируйте `cameras.json` чтобы задать понятные имена:

```json
{
    "pci-0000:00:14.0-usb-0:10:1.0:1.0": {
        "name": "cam_left",
        "port": "usb-0:10:1.0"
    },
    "pci-0000:00:14.0-usb-0:2:1.0:1.0": {
        "name": "cam_right",
        "port": "usb-0:2:1.0"
    }
}
```

### 3. Захват фотографий

```bash
python capture.py
```

Скрипт:

- Загрузит конфигурацию из `cameras.json`
- Просканирует подключённые камеры
- Сделает снимок с каждой камеры
- Сохранит фото в папку `photos/`

## Формат имени файла

```
YYYYMMDD_HHMMSS_{camera_name}.jpg
```

Пример: `20250115_143022_cam_left.jpg`

## Решение проблем

### Камеры не обнаружены

1. Проверьте подключение камер:

   ```bash
   ls -la /dev/v4l/by-path/
   ```
2. Установите v4l-utils:

   ```bash
   sudo apt install v4l-utils
   ```
3. Проверьте права доступа:

   ```bash
   sudo usermod -aG video $USER
   # Перелогиньтесь
   ```

### Ошибка открытия камеры

- Убедитесь что камера не используется другим процессом
- Проверьте права доступа к `/dev/video*`
- Попробуйте переподключить камеру

### Неверные имена камер в конфиге

- Удалите `cameras.json` и запустите `python capture.py --init` заново
- Или отредактируйте файл вручную
